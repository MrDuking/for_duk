# Câu chuyện của Duk 🚀

Một trò chơi 3D first-person kể về hành trình cuộc đời của Duk, xây dựng bằng **Three.js** và **Vite**.

## Tính năng

- 🌏 **Thế giới 3D tự do** – khám phá 4 vùng đất đại diện cho các chương cuộc đời
- 🎯 **First-person controls** – WASD / mũi tên để di chuyển, chuột để nhìn xung quanh
- 📖 **Story panels** – mỗi vùng đất có câu chuyện riêng xuất hiện khi bạn tiếp cận
- 🌟 **Hiệu ứng đẹp** – sao trời, đom đóm, tinh thể nổi, ánh sáng động
- 📊 **Progress bar** – theo dõi số chương đã khám phá

## Các chương

| Chương | Màu sắc | Nội dung |
|--------|---------|----------|
| 🌱 Tuổi Thơ | Vàng | Ngôi nhà nhỏ, sân chơi, cầu trượt |
| 📚 Tuổi Học Trò | Xanh dương | Trường học, sân bóng, đèn đường |
| ✨ Những Giấc Mơ | Tím | Tinh thể nổi, bàn máy tính, bầu trời mơ |
| 🚀 Tương Lai | Xanh cyan | Tên lửa, trụ ánh sáng, con đường |

## Cách chạy

```bash
# Cài đặt dependencies
npm install

# Chạy development server
npm run dev

# Build production
npm run build
```

## Điều khiển

| Phím | Hành động |
|------|-----------|
| `W A S D` / `↑ ↓ ← →` | Di chuyển |
| Chuột | Nhìn xung quanh |
| `Space` / `E` | Nhảy |
| `F` / `Enter` | Đóng hộp thoại |
| Click | Kích hoạt pointer lock |

## Tech stack

- [Three.js](https://threejs.org/) v0.176
- [Vite](https://vitejs.dev/) v6.4
